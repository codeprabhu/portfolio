# Shrivaths.dev

A cyberpunk-inspired personal portfolio built with Next.js, TypeScript, and TailwindCSS.

## Live Website

**Portfolio:** https://shrivaths.vercel.app

## Features

* Terminal-inspired user interface
* Interactive project explorer
* Professional experience timeline
* Responsive mobile design
* SakuraCam panorama viewer (desktop only)
* Hidden Nyan Cat easter egg 
* Custom cyberpunk aesthetic with Catppuccin theme

## Tech Stack

### Frontend

* Next.js
* React
* TypeScript
* TailwindCSS

### Design

* Catppuccin Color Palette
* Responsive Layout
* Custom Animations

## Local Development

```bash
npm install
npm run dev
```

Open:

```txt
http://localhost:3000
```

## Build

```bash
npm run build
npm start
```
